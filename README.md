# Module 9 — Audit metrics, code, and claims

## Start here

Open this folder in VS Code and run:

```text
uv sync --frozen
```

Open `module09_in_class.ipynb` and select the repository's `.venv` Python kernel. Predict each result before running the code. All example data is included.
